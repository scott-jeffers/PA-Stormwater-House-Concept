# PA Stormwater: New Single-Family Home (concept)

A one-page, plain-language dashboard of the stormwater and erosion-control requirements for building one new single-family house on a rural lot of about 8.5 acres in Bedminster Township, Bucks County, Pennsylvania.

**View it:** https://scott-jeffers.github.io/PA-Stormwater-House-Concept/

The page covers:
- Bedminster Stormwater Ordinance No. 239, §106 exemption check (Tables 106.1 / 106.2)
- Scenarios for whether the existing driveway counts toward the limit
- PA Chapter 102 E&S plan and NPDES thresholds
- A step-by-step checklist, the contents of a simple E&S plan, drainage tips, and a rough 2-inch-capture sizing calculator

Planning guidance only, not a sealed engineering design. Confirm with the township and the Bucks County Conservation District.
